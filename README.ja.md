# safari-profile

[English](README.md) | 日本語

Safariのプロファイルウインドウをコマンド一発で切り替えるCLIツールです。

- 指定したプロファイルのウインドウが**既に開いていれば最前面に切り替え**(最小化されていれば復元)
- **なければ新規作成**(「ファイル > 新規ウインドウ > 新規◯◯ウインドウ」を自動でクリック)

Safari本体のAppleScriptにはプロファイルを操作するAPIがまだ無いため、ウインドウタイトルの「`プロファイル名 — ページ名`」形式とメニュー操作を利用して実現しています。メニュー項目名を直接指定しない実装のため、日本語・英語どちらのUI言語でも動作します。

## 動作要件

- macOS Sonoma 以降 / Safari 17 以降(プロファイル機能があること)
- Safariでプロファイルを作成済みであること(Safari > 設定 > プロファイル)

## インストール

```bash
# このリポジトリをクローン
cd safari-profile
./install.sh
```

`~/.local/bin/safari-profile` にインストールされます。PATHが通っていない場合は `install.sh` が案内を表示します。インストール先を変えたい場合は `INSTALL_DIR=/usr/local/bin ./install.sh` のように指定してください。

## 使い方

```bash
safari-profile Work     # Workプロファイルへ切り替え(なければ新規作成)
safari-profile 個人用    # デフォルトプロファイルへ(英語環境では Personal)
```

引数のプロファイル名は、Safariの「ファイル > 新規ウインドウ」サブメニューに表示される名前(「新規**◯◯**ウインドウ」の◯◯部分)と一致させてください。

### 必要な権限

初回実行時に以下の許可を求められます(実行元のアプリごとに1回だけ):

- **オートメーション**: 「Safari」と「System Events」の制御 → 許可
- **アクセシビリティ**: メニュークリックに必要 → 実行元のアプリ(ターミナル、Alfredなど)を「システム設定 > プライバシーとセキュリティ > アクセシビリティ」でオンにする

## ショートカット.appに登録してキーボードショートカットで起動する

どのアプリからでもキー一発で切り替えられるようになります。

1. ショートカット.appで新規ショートカットを作成する
2. アクション「**シェルスクリプトを実行**」を追加する
   - アクションが見つからない場合: ショートカットの設定 > 詳細 > 「**スクリプトの実行を許可**」をオンにする
3. スクリプト欄に以下を入力する(フルパスで指定すること)

   ```bash
   $HOME/.local/bin/safari-profile Work
   ```

4. 右上のⓘ(詳細)パネルで「**キーボードショートカット**」に好きなキーを割り当てる
5. プロファイルごとにショートカットを複製する(例: 「Safari Work」「Safari Personal」)

### アクセシビリティ権限の設定(重要)

ショートカット.app経由では実行主体が `osascript` になるため、初回は
`osascript is not allowed assistive access. (-1719)` エラーが出ます。以下で解決します:

1. システム設定 > プライバシーとセキュリティ > **アクセシビリティ** を開く
2. 「＋」をクリックし、ファイル選択ダイアログで **⌘⇧G** を押して `/usr/bin/osascript` と入力して追加
3. 追加された **osascript** のトグルをオンにする

### キーボードショートカット選びの注意

最前面アプリのメニューショートカットはグローバルショートカットより優先されます。特にSafariは **W キーの組み合わせをほぼ使い切っています**(⌘W / ⇧⌘W / ⌥⌘W / ⇧⌥⌘W / ⌃⌘W はすべて使用済み。⌃⌘W は「タブグループを削除」)。

**⌃⌥⌘ + 文字**(例: Work → `⌃⌥⌘W`、個人用 → `⌃⌥⌘P`)は標準アプリのメニューとほぼ衝突しないためおすすめです。

なお、ショートカット.appは起動していなくてもキーボードショートカットは発火します(システムのバックグラウンドプロセスが処理します)。Spotlightからショートカット名で実行することも可能です。

## 制限事項

- ウインドウタイトルが「`プロファイル名 — `」で始まることに依存しています(Safari 17〜26で確認)。Safariの仕様変更で動かなくなる可能性があります
- プライベートブラウズウインドウは対象外です
- 新規作成時はSafariの「ファイル」メニューをUI操作でクリックするため、アクセシビリティ権限が必須です
